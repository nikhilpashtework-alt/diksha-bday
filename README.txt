DIKSHA'S BIRTHDAY WEBSITE — NIKHIL

Files:
- index.html
- style.css
- script.js
- images/ (put your own photos here)

HOW TO ADD PHOTOS
Copy your photos into the images folder and use these exact filenames:
hero.jpg          (background of the opening screen)
couple-1.jpg
grass-1.jpg
couple-2.jpg
memory-1.jpg
couple-3.jpg
memory-2.jpg
memory-3.jpg
grass-3.jpg
grass-2.jpg       (photo in the birthday-wish section)

You can change captions and photo filenames in script.js, in CONFIG.memories.
If a photo is missing, the gallery displays a gentle placeholder rather than a broken-image icon.
Use .jpg filenames or update the matching paths to .png/.webp if needed.

PREVIEW
Open index.html in your browser. For the most reliable preview, use VS Code's Live Server extension.

HOSTING
Upload the entire folder, including index.html, style.css, script.js and images, to a static website host.
The Google Fonts import requires an internet connection; fallback fonts are included.
